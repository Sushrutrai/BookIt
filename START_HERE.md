## ⚡ 60-Second Overview

**What it does:**
- Event organizers can create custom ticket tiers (VIP, Standard, etc.) when creating events
- Each tier has: custom name, price, capacity, and optional sale dates
- Admins add/remove tiers dynamically with buttons
- Everything saved to database automatically

**What's included:**

```

  - Check if ticket_type table exists
  - If not, run CREATE TABLE statement from SETUP_GUIDE.md

Step 2: Backup originals
  - cp admin/addEventForm.php admin/addEventForm.php.backup
  - cp app/actions/controller.php app/actions/controller.php.backup

Step 3: Test → Deploy
  - Copy _new files to staging and test
  - When ready, replace production files
  - Clear browser cache
  - Test live system
```
